# VBOOK-08 — Build the first ElevenLabs conversational agent

**Priority:** P0
**Goal:** Learn the ElevenLabs API before connecting it to complicated backend behavior.

## Description

Create the simplest possible ElevenLabs agent and understand its lifecycle.

Do **not** integrate booking functionality yet.
